Tree Tower

A cozy mobile building game concept where players grow a vertical village by stacking and upgrading tree houses.

Academic concept — not a client projectDraft page — original images still needed

Academic concept
Platform
Figma
Scope
App design

Image neededHero: two phones showing the Tree Tower build screen and tower view

01Challenge

Simple idea, clear interface.

Turn a simple stacking-game idea into an interface that feels playful and easy to understand, while still supporting building choices, resources, upgrades and progression.

02Goal

The world stays the hero.

Create a cohesive experience where the fantasy world remains the focus, while controls, stats and actions stay clear enough for quick mobile interaction.

03Core flow

Four repeatable actions.

The main flow is organised around four actions: view the tower, choose a structure, review its attributes, and build or upgrade it.

  1. 01HomeView the tower.
  2. 02BuildChoose a house.
  3. 03PreviewCheck its stats.
  4. 04BuildPlace it and grow.

04Visual direction

Wood, forest and warmth.

The interface borrows its look from the game world: wooden controls, deep teal forest backgrounds, warm orange roofs, cream information cards and simple icons. This helps interface elements feel part of the environment, not layered on top of it.

  • Forest Teal#173F3D
  • Warm Wood#A94F22
  • Cream#F4EFE4
  • Moss#72865B

05Final UI

One system across the game.

The same buttons, resource counters and cards run through every screen, so navigation and information stay consistent.

06Outcome

A clearer game concept.

The final direction turns Tree Tower into a more complete mobile-game concept, connecting the playful visual world with a clear interface for building, upgrading and tracking progress. Designing the system across several screens made it easier to keep navigation, buttons, resources and information consistent.
